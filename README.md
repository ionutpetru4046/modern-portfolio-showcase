# Modern Portfolio Showcase

A feature-rich portfolio website designed to highlight your professional skills, projects, and experience with a modern, clean user interface. Deployed at: [modern-portfolio-showcase-opal.vercel.app](https://modern-portfolio-showcase-opal.vercel.app/)

---

## Overview

Modern Portfolio Showcase is a responsive web application built to present personal or professional portfolios. It provides a visually appealing, easy-to-navigate layout optimized for desktop and mobile devices.

---

## Demo

🌐 **Live Site:** [https://modern-portfolio-showcase-opal.vercel.app/](https://modern-portfolio-showcase-opal.vercel.app/)

---

## Features

- Clean, modern UI/UX
- Responsive design for all devices
- Animations and interactive components
- Easy to customize sections: About, Projects, Skills, Contact
- Notification support with [react-hot-toast](https://react-hot-toast.com/)
- Powered by cutting-edge frontend technologies

---

## Built With

- **Vite** – Lightning fast frontend tooling
- **TypeScript** – Static type checking for robust code
- **React** – Component-based UI library
- **shadcn/ui** – Accessible, customizable UI components
- **Tailwind CSS** – Utility-first CSS framework for rapid UI development
- **react-hot-toast** – Beautiful notifications & toasts

## Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd modern-portfolio-showcase
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
4. **Open [http://localhost:5173](http://localhost:5173) to view it in the browser.**
